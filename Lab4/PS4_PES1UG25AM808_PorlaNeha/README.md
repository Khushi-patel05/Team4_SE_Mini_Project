# Lab 4 — Rock Paper Scissors

## Project Overview
A Rock Paper Scissors game developed using Python and Pygame as part of the Software Engineering Lab 4 (VibeCoding).

## Implemented Features
- Fixed inverted winner evaluation.
- Implemented a First-to-5 match system.
- Added adaptive AI using player move history.
- Added animated gesture visuals.
- Added a Restart button to reset the match.

## Technologies Used
- Python
- Pygame
- Git and GitHub

## Project Structure
- `source-code/` — Python source files.
- `videos/` — Before and after demonstration videos.
- `Chat_History.pdf` — Organized AI-assisted development history.

## How to Run
Install Python, then install Pygame:

```bash
pip install pygame
```

Run the game from the project directory:

```bash
python main.py
```

## Testing
The game was tested for winner evaluation, adaptive AI behavior, match completion at five wins, gesture animations, and restarting the match.
